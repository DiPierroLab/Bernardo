## Provenance

The native chromatin structures used in this work were generated using the NuChrom model developed by Ailun Wang and collaborators.

NuChrom is a nucleosome-resolution polymer modeling framework that reconstructs ensembles of chromatin conformations from Hi-C data.

A small subset of representative structures is included in this repository for inspection. The full ensemble is not included due to size constraints.

For the full structure ensemble, see:
- NuChrom repository: https://github.com/DiPierroLab/NuChroM

Associated publication:
- Harris, H. L. et al.  
  *Chromatin alternates between A and B compartments at kilobase scale for subgenic organization.*  
  Nature Communications 14, 3303 (2023).
