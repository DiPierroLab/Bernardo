# In-silico Hi-C simulations: data and code

This repository contains the data and analysis code supporting the manuscript:

**“Understanding the physical processes behind DNA–DNA proximity ligation assays.”**

---

## Overview

This work studies the physical mechanisms underlying DNA–DNA proximity ligation assays (e.g., Hi-C) using **in-silico simulations**. Chromatin is modeled at nucleosome resolution and evolved using molecular dynamics. A virtual Hi-C protocol explicitly implements:

* Crosslinking of chromatin to a protein matrix
* Enzymatic digestion of DNA
* Proximity ligation of DNA ends

Simulations are performed over ensembles of chromatin structures, enabling the construction of ligation maps and the analysis of ligation and contact probabilities as functions of genomic and Euclidean distance.

This repository contains the final processed outputs and code necessary to reproduce all figures in the manuscript.

---

The repository includes:

## Pipeline summary

The in-silico Hi-C workflow is organized into five stages:

1. **FIRE minimization**
   Input chromatin structures are energy-minimized.

2. **MD simulation with crosslinking and digestion**
   Langevin dynamics simulations are performed with crosslinking constraints and DNA fragmentation.

3. **Ligation analysis**
   Fragment ends that come within a threshold distance may ligate according to a probabilistic rule, provided they have not previously ligated.

4. **Aggregation**
   Per-trajectory outputs are combined into ensemble-averaged observables, including:

   * Ligation-derived maps and probabilities (Hi-C–like readouts)
   * Trajectory-derived contact maps and distance statistics (ground-truth structural observables)

5. **Plotting**
   Aggregated data are used to generate manuscript figures. Representative Jupyter notebooks demonstrate how figures are produced.

See the README files within each stage directory under `scripts/` for detailed descriptions.

## Data availability and limitations

* Raw molecular dynamics trajectories (multiple terabytes) are **not included**.
* Intermediate per-trajectory analysis files are **not included**.
* The repository provides **final, post-aggregation outputs** sufficient to reproduce reported results and figures.

## Chromatin structures

Input chromatin structures were generated by **Ailun Wang** using the NuChrom model.

* These structures are **external inputs** and are not generated by the code in this repository.
* Only a **small subset** is included for demonstration and testing.
* This subset is **not sufficient to reproduce ensemble-averaged results**.

For the full structure ensemble, see:

* NuChrom repository: https://github.com/DiPierroLab/NuChroM
* Associated publication:
  Harris, H. L. *et al.*
  *Chromatin alternates between A and B compartments at kilobase scale for subgenic organization*
  Nature Communications 14, 3303 (2023)

## Reproducing results

To reproduce the figures:

1. Set up a compatible Python/conda environment
2. Use the processed `.npz` files in `data/processed/` as input
3. Run the plotting notebooks in `scripts/05_plotting/`

The provided data are sufficient to reproduce figures without rerunning the full MD simulations.
